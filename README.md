# Video Games Analysis Dashboard

## 📌 Project Overview

The **Video Games Analysis Dashboard** is an interactive business intelligence project developed using Microsoft Power BI to analyze global video game sales data across different platforms, genres, years, and regions.

The dashboard transforms raw gaming sales data into meaningful insights through data visualization, trend analysis, and KPI tracking. It helps users understand market behavior, platform popularity, sales performance, and genre trends in the gaming industry.

The project focuses on:

* Data Cleaning
* Data Transformation
* Data Visualization
* Trend Analysis
* Interactive Dashboarding
* Business Insights Generation

The dashboard contains multiple pages with slicers, filters, KPI cards, and dynamic visualizations for detailed exploration of the dataset. 

---

# 🎯 Project Objectives

* Analyze global video game sales data
* Identify top-performing gaming platforms
* Discover the most popular game genres
* Compare sales performance across regions
* Analyze yearly game release trends
* Study relationship between games released and games sold
* Create an interactive dashboard for business decision-making

# 📊 Dashboard Pages & Features

## 1️⃣ Home Dashboard

The home dashboard provides an overview of:

* Total games sold
* Most popular genres
* Highest selling regions
* Top-selling games
* Top platforms

Key insights displayed include:

* North America as the highest-selling region
* Action genre as the most popular genre
* Wii Sports as the top-selling game 

---

## 2️⃣ Platforms Analysis

This page analyzes the performance of gaming platforms.

### Key Findings

* PS2 is the highest-selling platform
* Xbox 360 and PS3 also show strong sales performance
* Older platforms show comparatively lower sales

The dashboard visualizes platform-wise sales comparison using bar charts. 

---

## 3️⃣ Games Released by Year

This section studies yearly game release patterns.

### Insights

* Game releases increased rapidly after 2000
* Peak releases occurred around 2008–2010
* Releases declined after 2012

It also includes:

* Cumulative games released over time
* Yearly release trend analysis 

---

## 4️⃣ Games Sold by Year

This page analyzes yearly sales performance.

### Insights

* Global sales peaked between 2007–2009
* Sales declined gradually after 2010
* Earlier years had limited sales volume

This helps identify industry growth and decline periods. 

---

## 5️⃣ Sold vs Released Analysis

This section compares:

* Number of games released
* Average sales performance

### Key Observations

* Higher releases do not always mean higher sales
* Certain years achieved better average sales with fewer releases
* Sales efficiency changed over time

This analysis helps evaluate market saturation and performance quality.
